# 🧰 Outils PCperso — Index

Ressources pratiques pour planifier une configuration, vérifier les points de compatibilité, suivre le budget et préparer le montage. Les données évoluent : valide toujours les spécifications et tarifs dans les sources officielles et locales.

| Ressource | Quand l’utiliser | Accès |
|:--|:--|:--|
| Configurations types | Pour comparer des bases par usage et budget. | [Ouvrir](./configs-types.md) |
| Vérificateur de compatibilité | Pour organiser les contrôles de compatibilité avant achat. Ce n’est pas une certification automatique. | [Ouvrir](./verificateur-compatibilite-2026.md) |
| Budget et puissance | Pour suivre les dépenses et étudier les besoins électriques estimés. | [Ouvrir](./calculateur-budget-puissance.md) |

| Fiche mémo | Pour consulter les contrôles de câblage et de démarrage. | [Ouvrir](./fiche-memo-cablage-et-debug.md) |
| Guide d’upgrade | Pour planifier l’évolution d’un PC existant. | [Ouvrir](./guide-upgrade-pc.md) |

## Parcours conseillé

1. Définis usage, résolution visée et budget global.
2. Parcours les [configurations types](./configs-types.md) comme exemples, pas comme recommandations de prix garanties.
3. Vérifie chaque référence dans les manuels des fabricants et avec le [vérificateur](./verificateur-compatibilite-2026.md).
4. Estime la puissance avec le [guide budget/PSU](./calculateur-budget-puissance.md), puis confirme les connecteurs et recommandations fabricant.
5. Utilise la [checklist de montage](../CHECKLIST.md) le jour de l’assemblage.
